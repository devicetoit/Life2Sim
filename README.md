# Life2Sim

**家族の未来を描く、精緻なライフプランシミュレーター**

Life2Sim は、家族構成・収入推移・住宅ローン・投資運用・教育費・税金・社会保険料など、家計に関わるあらゆるパラメータを入力し、数十年先までの年次別キャッシュフローと資産残高を推計するWebアプリケーションです。

日本の税制・社会保険制度のルールデータを内蔵しており、単なる概算ツールではなく、制度ベースの計算ロジックに基づいた本格的なシミュレーションを提供します。

## 主な機能

- **詳細な家計シミュレーション** — 年単位・年齢別の詳細な収支推移と資産残高を計算
- **ダッシュボード** — 資産推移・収支推移を視覚的なグラフ（Recharts）で表示
- **柔軟なパラメータ設定**:
  - **家族構成**: 複数メンバー、生年、続柄（世帯主・配偶者・子）の設定
  - **収入**: 給与（ピーク年齢・昇給カーブ設定）、年金（繰上げ/繰下げ調整）、退職金など
  - **資産・運用**: 短期・中長期別の資産管理、利回り計算、DC/NISA積立（制度上限自動適用）
  - **生活費**: カテゴリ別の詳細内訳（月額）と、ライフステージに応じたステップ設定
  - **住宅**: 購入時期、ローン設定（段階金利・団信・全疾病保障対応）
  - **ライフイベント**: 旅行、車両購入、リフォーム等、イベント別のインフレ率考慮
  - **個人固定費**: 保険・通信費・お小遣い等の個人別固定支出
- **制度ベースの税・社会保険計算** — 所得税・住民税の累進課税、社会保険料（健康保険・厚生年金・雇用保険・介護保険）を制度ルールに基づき自動計算
- **リスクシミュレーション** — 世帯主の死亡シナリオ（遺族年金合算・生活費係数調整）
- **データ管理** — JSON形式でのインポート/エクスポート、Supabase連携によるクラウド保存

## 計算ロジックの詳細

このシミュレーターは、世帯主の年齢を軸に年次ループでキャッシュフローと資産残高を計算します。以下に、各計算領域のロジックと仮定を詳述します。

### 1. 収入

#### 給与所得のモデリング

給与の推移は以下の3パターンをサポートします：

**a) ピーク年収モデル（推奨）**

開始年収 → 目標ピーク年収へ向かい、**パワー関数カーブ**（1.4乗）で段階的に収束します。

```
gross = startAmount + (peakAmount - startAmount) × (1 - (1 - ratio)^1.4)
  ※ ratio = (現在年齢 - 開始年齢) / (ピーク年齢 - 開始年齢)
```

この設計により、キャリア初期の昇給ペースが速く、ピークに近づくほど伸びが鈍化する現実的なS字型のカーブを再現します。

ピーク到達後は **2年間のプラトー（横ばい）** の後、年率で微減します（デフォルト0.5%/年）。

```
gross = peakAmount × (1 - decayRate)^(経過年数 - 2)
```

**b) 定率昇給モデル**

毎年一定率で複利成長するシンプルなモデルです。

```
gross = baseAmount × (1 + annualGrowthRate)^経過年数
```

**c) 固定額モデル**

開始から終了まで一定額の収入を想定します。パート収入や再雇用時の給与など、変動が小さいケースに適しています。

### 2. 税金

所得税・住民税は、国税庁等の公開ルールに基づく **制度ベースの計算** を行います。実装データは `src/rules/tax.json` に外部化されており、制度改正時にJSONを更新するだけで追従可能です。

#### 所得税の計算フロー

```
① 給与収入 → 給与所得控除を適用 → 給与所得
② 公的年金収入 → 公的年金等控除を適用（65歳以上/未満で異なる） → 年金所得
③ 合計所得 = 給与所得 + 年金所得
④ 課税所得 = 合計所得 - 基礎控除 - 社会保険料控除 - その他控除（配偶者・医療費等）
⑤ 所得税 = 累進税率テーブルに基づき算出
⑥ 復興特別所得税 = 所得税 × 2.1%
```

**累進税率テーブル（組み込み済み）**:

| 課税所得 | 税率 | 控除額 |
|---|---|---|
| 〜194.9万円 | 5% | 0円 |
| 〜329.9万円 | 10% | 9.75万円 |
| 〜694.9万円 | 20% | 42.75万円 |
| 〜899.9万円 | 23% | 63.6万円 |
| 〜1,799.9万円 | 33% | 153.6万円 |
| 〜3,999.9万円 | 40% | 279.6万円 |
| 4,000万円〜 | 45% | 479.6万円 |

#### 住民税

```
住民税 = 課税所得 × 10%（所得割） + 均等割（デフォルト5,000円）
```

均等割はユーザーが都道府県の森林環境税等を含めてカスタマイズ可能です。

### 3. 社会保険料

社会保険料は **会社員モデル** と **国保モデル（自営業等）** の2種類をサポートします。

#### 会社員モデル（`employee`）

各保険料は **標準報酬月額** と **標準賞与額** をベースに算出されます。

**健康保険**:
- 全国47都道府県の協会けんぽ保険料率を内蔵（例: 東京9.91%）
- 労使折半（被保険者負担50%）
- 標準報酬月額の上限: 139万円 / 下限: 5.8万円
- 標準賞与の年間上限: 573万円

**厚生年金保険**:
- 保険料率: 18.3%（労使折半で本人負担9.15%）
- 標準報酬月額の上限: 65万円 / 下限: 8.8万円
- 1回の賞与上限: 150万円

**介護保険**:
- 40歳〜64歳の被保険者に適用
- 保険料率: 1.59%（労使折半）

**雇用保険**:
- 一般の事業: 本人負担0.55%
- 農林水産・清酒製造: 本人負担0.65%
- 建設: 本人負担0.65%

**賞与のモデリング**:
ユーザーが指定した `salaryBonusRatio`（年収に占める賞与割合）と `bonusPaymentsPerYear`（年間賞与回数）に基づき、月額報酬と賞与を分離して各保険の標準報酬月額・標準賞与額を計算します。

#### 国保モデル（`national`）

自営業・フリーランスの場合は、国民健康保険料と国民年金を固定額ベースで設定します。
- 世帯基礎額、1人あたり額を入力
- 国民年金は月額・対象年齢区間を指定

### 4. 年金

#### 老齢基礎年金

2025年4月時点の制度データに基づきます。

- **満額**: 年額831,696円（月額69,308円）
- **デフォルト受給開始年齢**: 65歳
- ユーザーが入力した「基礎年金」は、受給開始年齢に基づき繰上げ/繰下げの自動調整が適用されます

**繰上げ受給**:
```
減額率 = 月数 × 0.4%（最大24%減額、最大60ヶ月）
```

**繰下げ受給**:
```
増額率 = 月数 × 0.7%（最大84%増額、最大120ヶ月）
```

#### 老齢厚生年金

厚生年金は、報酬比例部分であるため個人の加入記録に大きく依存するため、ユーザーがねんきんネット等から取得した「見込額」を直接入力する方式を採用しています。

### 5. 住宅ローン

#### 元利均等返済の計算

**段階金利（変動金利を含む）** に対応しています。返済全期間を複数の金利期間に分割し、各段階で残債に対して元利均等の月次返済額を再計算します。

```
月次返済額 = 残債 × 月利 × (1 + 月利)^残回数 / ((1 + 月利)^残回数 - 1)
  ※ 月利 = (段階金利 + 団信上乗せ + 全疾病保障上乗せ) / 100 / 12
```

各年の返済額を事前計算し、年次ループで参照します。月ごとに元金返済分・利息分を分離して残債を更新するため、段階金利移行時の残債が正確に反映されます。

**その他の住宅関連費用**:
- 頭金: 購入年に一括計上
- 維持・管理費: 年額（インフレ率適用）
- 購入前の家賃: 月額 × 12（インフレ率適用）

### 6. 生活費

生活費は **カテゴリ別の月額** × **12ヶ月** × **インフレ率** で年額を算出します。

**カテゴリ構成**: 食費、通信費、日用品費、光熱費、住居費、趣味・娯楽費、その他

**ライフステージ別ステップ設定**: 世帯主年齢に応じて、異なる生活費内訳を定義できます。例えば「35歳〜」「45歳〜（子の成長）」「65歳〜（退職後）」のように、段階的な変化を表現します。

**インフレ率の適用**:
```
年間生活費 = 月額合計 × 12 × (1 + 生活費インフレ率)^経過年数
```

### 7. 教育費

教育費は **テンプレートベース** で計算されます。

**デフォルトテンプレート**（子ども1人あたりの年額目安）:

| 年齢 | 段階 | 年額（万円） |
|---|---|---|
| 4〜5歳 | 幼稚園 | 40 |
| 7〜12歳 | 小学校 | 30 |
| 13〜14歳 | 中学校 | 50 |
| 15歳 | 中学校（受験年） | 80 |
| 16〜17歳 | 高校 | 60 |
| 18歳 | 高校（受験年） | 100 |
| 19〜22歳 | 大学 | 150 |

**累計金額のオーバーライド**: テンプレートの合計金額を維持したまま、目標総額（例: 2,000万円）にスケーリングできます。テンプレートの各年の比率は保持されるため、年齢ごとの配分バランスは崩れません。

```
スケーリング係数 = 目標総額 / テンプレート合計額
各年の教育費 = テンプレート年額 × スケーリング係数 × (1 + 教育費インフレ率)^経過年数
```

### 8. 児童手当

2025年以降の新制度ルールに基づき、子どもの人数・年齢に応じて **自動計算** されます。

| 条件 | 月額 |
|---|---|
| 3歳未満 | 15,000円 |
| 3歳〜小学校修了前（第1・2子） | 10,000円 |
| 3歳〜小学校修了前（第3子以降） | 15,000円 |
| 中学生〜高校生（18歳まで） | 10,000円 |

- 所得制限は撤廃（2024年12月〜）された新制度に準拠
- 年額に変換して収入に自動加算

### 9. 資産運用・積立

#### 資産の区分

資産は **タイプ**（現金・投資信託・DC）と **期間**（短期・中期・長期）の2軸で管理します。

#### 運用利回り

各資産に設定された年利で複利運用されます。

```
年間利息 = 残高 × (年利率 / 100)
年末残高 = 年初残高 + 年間利息 + 年間積立額
```

#### NISA/iDeCo の上限キャップ

積立名に「NISA」が含まれる場合:
- **年間上限**: 360万円（つみたて120万円 + 成長240万円の合計枠）

積立名に「iDeCo」または「DC」が含まれる場合、カテゴリに応じた月額上限:
- 自営業: 68,000円/月
- 企業年金なしの会社員: 23,000円/月
- 企業年金ありの会社員: 20,000円/月
- 公務員: 20,000円/月
- 専業主婦(夫): 23,000円/月

### 10. ライフイベント

ライフイベントは以下の4カテゴリに分類され、それぞれキャッシュフロー上の扱いが異なります。

| カテゴリ | 扱い | 例 |
|---|---|---|
| `future_plan` / `other` | 経常支出（計画的支出） | 旅行、車購入等 |
| `irregular` | 臨時支出（不定期支出） | 車両買替、リフォーム |
| `education_fund` | 臨時収入（学資満期金） | 学資保険の満期返戻 |
| `surrender_value` | 臨時収入（解約返戻金） | 保険の解約返戻金 |

**イベントタイプ**:
- 一回限り（`one_time`）: 指定年齢に1回発生
- 定期的（`periodic`）: 開始〜終了年齢の間、指定間隔で発生

**インフレ補正**: 各イベントに個別のインフレ率カテゴリ（`inflation`, `living`, `none`等）を設定可能。`none` を指定すれば名目固定額となります。

### 11. 資産取り崩しと移管

#### 赤字時の自動取り崩し

年次のキャッシュフローが赤字の場合、以下の優先順位で資産を取り崩します:

1. **現金（預貯金）** を優先的に取り崩し
2. 現金が不足する場合、**投資資産** を売却して補填

#### 資産の移管（一括現金化）

設定した年齢（デフォルト: 65歳）に到達すると、投資信託やDCの残高を一括で現金に移管します。これは退職時の一括受取りや、リスク資産からの撤退をシミュレーションするための機能です。

- 投資信託とDCの移管年齢は個別に設定可能
- 「老後取り崩し戦略」を有効にすると、投資のまま保持して段階的に取り崩すモードに切り替わります

### 12. 死亡シナリオ（万一シミュレーション）

世帯主が指定年齢で死亡した場合の家計への影響を試算します。

**死亡年に発生する費用**:
- 葬儀費用（デフォルト: 200万円）
- 予備費（デフォルト: 50万円）
- 生活立て直し資金（デフォルト: 100万円）

**生活費の変動**:
- 死亡後の生活費 = 通常生活費 × `livingCostFactor`（デフォルト: 0.7 = 30%削減）
- 末子が独立年齢（デフォルト: 22歳）に達した後: さらに `independentChildFactor`（デフォルト: 0.5）を乗算

**遺族年金（簡易計算）**:

遺族基礎年金:
- 基本額: 81.6万円/年（2024年概算値）
- 第1子加算: +23.5万円、第2子加算: +23.5万円、第3子以降: +7.8万円/人
- 18歳年度末までの子がいる場合のみ支給

遺族厚生年金（簡易推定）:
```
遺族厚生年金 ≒ 死亡時の額面年収 × 12%
```

> **注意**: 本来は報酬比例部分の3/4で算出されますが、加入期間の情報なしに正確な計算はできないため、概算値として年収の12%を適用しています。

## シミュレーションの限界と注意点

このシミュレーターは多くの制度ルールを内蔵していますが、現実の家計を完全に再現するものではありません。以下の限界を理解した上でご利用ください。

### 税制関連

- **投資収益への課税は非考慮**: 運用利回りは税引後ではなく税引前で計算されます。NISA口座内の非課税メリットや、特定口座での源泉徴収は反映されません。
- **退職所得控除は非考慮**: 退職金に対する退職所得控除の適用は行っていません。退職金を入力する際は、手取り相当額を入力することを推奨します。
- **扶養控除・配偶者特別控除の細かな所得制限**: 現在は追加控除としてユーザーが金額を直接入力する方式であり、所得に応じた自動判定は行っていません。
- **ふるさと納税等の税額控除**: 反映されません。

### 社会保険関連

- **標準報酬月額の等級テーブル**: 簡易的に端数処理（1,000円単位で切り捨て＋上下限クランプ）で近似しており、正式な等級表との差異がわずかに生じる場合があります。
- **70歳以降の社会保険**: 厚生年金は70歳で適用なしとしていますが、在職老齢年金の支給停止などは反映していません。

### 年金関連

- **遺族年金は簡易推定**: 遺族厚生年金を「年収 × 12%」で概算しており、実際の報酬比例部分（加入月数・標準報酬に基づく計算）とは差異があります。
- **中高齢寡婦加算・経過的寡婦加算**: 反映されていません。
- **加給年金・振替加算**: 反映されていません。
- **老齢厚生年金の報酬比例部分**: 個人の加入記録に依存するため自動計算できません。ねんきん定期便等の見込額を直接入力してください。

### 収入モデル

- **給与のパワーカーブ（1.4乗）** は一般的なサラリーマンの昇給パターンを概ね近似するものですが、業界・職種・昇進パターンによって実態は大きく異なります。ご自身のキャリアパスに応じて適宜調整してください。
- **ピーク後のプラトー期間（2年）** はハードコードされています。

### その他

- **インフレ率は全期間一定**: 現実には変動しますが、このシミュレーションでは設定した率で全期間を通じて複利計算します。
- **医療費・介護費の個別推計は非対応**: 70歳以降の高額な医療費・介護費用は「その他費用」やライフイベントとして手動で計上する必要があります。
- **相続税**: 反映されていません。
- **制度改正リスク**: 税率・社会保険料率・年金額等は将来改正される可能性があります。JSONデータの定期的な更新が推奨されます。

## データの取り扱いについて

- 入力データはブラウザの `localStorage` に保存されます。
- `src/store/initialData.ts` を編集することで初期設定のカスタマイズが可能です。
- Supabase を設定することで、Google認証によるクラウドへのデータ保存・同期が可能です。
- 機密性の高い個人的なデータやバックアップは `/private/` フォルダ（Git除外設定済み）に保存することを推奨します。
