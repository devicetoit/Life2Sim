# Life2Sim AI相談用データ

## 推奨プロンプト

以下のライフシミュレーション設定と結果を読み取り、家計・資産形成・住宅・教育費・働き方・老後資金の観点から分析してください。
特に次の点を重視してください。

1. 年ごとの赤字そのものは問題視しすぎず、資産合計が0円以下になるリスクを中心に見てください
2. 何歳ごろに、どの要因で資産が大きく減りやすいかを特定してください
3. 資産が0円以下にならないための改善案を、効果の大きい順に3〜5個提示してください
4. 住宅予算、働き方、教育費、投資積立、老後支出のうち、どこを動かすのが最も効率的かを示してください
5. 単年赤字よりも、累積資産の維持・老後の資産寿命の延長を重視してください
6. 追加で確認すべき入力値や制度前提も挙げてください

回答は、
- まず資産が減る主要局面
- 次に資産が尽きないための改善案を優先順位順
- 最後に前提の不確実性
の順で整理してください。

## AIへの依頼

以下はライフシミュレーションの設定値と結果です。
年ごとの赤字は許容しつつ、資産合計が0円以下にならないことを重視したいです。
家計・資産形成・住宅・働き方・老後資金の観点から、資産寿命を伸ばすための弱点、改善案、前提の見直しポイントを分析してください。
特に、どの年齢帯で資産が削られやすいか、どの設定変更が最も効きやすいかを重視して評価してください。
