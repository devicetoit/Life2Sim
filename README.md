# Life2Sim

家族の未来を描くライフシミュレーターです。
家族構成、将来の収入推移、住宅ローン（段階金利対応）、投資資産の運用などを自由に入れ替え、精緻な収支計算が可能です。

## 主な機能

- **詳細な家計シミュレーション**: 年単位・年齢別の詳細な収支・資産残高の推移計算
- **ダッシュボード**: 資産推移、収支推移を視覚的なグラフで表示
- **柔軟なパラメータ設定**:
  - **家族構成**: 複数の家族メンバー、生年、続柄の設定
  - **収入**: 給与（ピーク年齢、昇給率設定）、年金、退職金など
  - **資産・運用**: 短期・中長期別の資産管理、利回り計算、DC/NISA積立
  - **生活費**: カテゴリ別の詳細内訳（月額）と、ライフステージに応じたステップ設定
  - **住宅**: 購入時期、ローン設定（段階金利、団信、全疾病保障対応）
  - **ライフイベント**: 旅行、車両購入、教育費、イベント別のインフレ率考慮
- **リスクシミュレーション**: 世帯主の死亡シナリオ（遺族年金合算対応）
- **データ管理**: JSON形式でのインポート/エクスポート機能

## 技術スタック

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **State Management**: Zustand (with Persist)
- **Charts**: Recharts
- **Icons**: Lucide React

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

## データの取り扱いについて

- 入力データはブラウザの `localStorage` に保存されます。
- `src/store/initialData.ts` を編集することで初期設定のカスタマイズが可能です。
- 機密性の高い個人的なデータやバックアップは `/private/` フォルダ（Git除外設定済み）に保存することを推奨します。
